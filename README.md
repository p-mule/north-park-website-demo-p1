# North Park School website

A four-page site for North Park School, Lusaka: Home, About us, Admissions and How to apply.

## Files

- `index.html` is the page itself and the file GitHub Pages looks for.
- `styles.css` holds the colours, fonts and layout.
- `script.js` switches between the pages and builds the application email.
- `images/` holds the logo and photos.

## Run it locally

Double-click `index.html` to open it in a browser.

## Publish it with GitHub Pages

1. Create a new repository on GitHub.
2. Upload everything in this folder, including the `images` folder, to the main branch.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then save.
4. After a minute or two, the live link appears at the top of the Pages settings.
